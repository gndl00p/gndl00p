# Philip Robb

I build useful things for the real world.

Most of my work sits at the intersection of IT, automation, infrastructure, embedded hardware, and small-business operations. I run [Robb Technology Group](https://robb.tech) in West Texas, so a lot of what I build comes from actual problems that need solved, not lab experiments.

## What I like building

- operational tools that save people time
- AI tooling that does real work
- infrastructure, networking, and security systems
- embedded and edge-device projects
- weather and decision-support tools

## Public projects

### [OpenBLS](https://github.com/gndl00p/openbls)
Open-source bilateral stimulation tool for licensed clinicians.

### [astro-asteroids](https://github.com/gndl00p/astro-asteroids)
Astro integration and JavaScript library that lets visitors blast apart your website for fun. Refresh and it all comes back.

### [vrefiq-recorder](https://github.com/gndl00p/vrefiq-recorder)
Open-source flight recorder for Stratux units that captures GDL90 data in flight and auto-uploads it to VrefIQ.

### [SkyGlance](https://github.com/gndl00p/skyglance)
Aviation weather on a Pimoroni Badger 2040 W. No server. No API key. No subscription.

## The kind of problems I work on

- turning messy operational problems into clean systems

- building practical software for service businesses
- making technical systems faster, simpler, and more useful

I like building things that are useful, fast, and not bloated to hell.
